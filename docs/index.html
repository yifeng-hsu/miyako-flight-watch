手機文字通知

符合提醒條件時，Telegram 會直接把票價資訊推播到手機，不需要開著這個網頁。

通知方式：Telegram 文字訊息
背景推播
每日約 09:05 查價 不增加 API 用量 只在重要價格變化時通知
設定 Telegram 文字通知
  1. 在 Telegram 搜尋 @BotFather，輸入 /newbot 建立機器人，然後開啟該機器人並傳送 /start。
  2. 取得 Bot Token 與 Chat ID。
  3. 到本專案 GitHub 的 Settings → Secrets and variables → Actions，新增 TELEGRAM_BOT_TOKEN 和 TELEGRAM_CHAT_ID。
  4. iPhone 到 設定 → 通知 → Telegram，開啟「允許通知」，並選擇鎖定畫面、通知中心與橫幅。

通知內容包含行程、4 人總價、每人價格與提醒原因。首次查到票價、刷新歷史低價、降價至少 5%，或低於目標總價時才會推播。Bot Token 屬於密碼，請只放在 GitHub Secrets，不要貼在網頁或聊天室。
