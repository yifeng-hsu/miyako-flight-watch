iPhone 關閉網頁後也要自動播報：設定方式
  1. 在 Telegram 建立機器人並傳送 /start，取得 Bot Token 與 Chat ID。
  2. 到本專案 GitHub 的 Settings → Secrets and variables → Actions，新增 TELEGRAM_BOT_TOKEN 和 TELEGRAM_CHAT_ID。
  3. iPhone 到 設定 → 輔助使用 → Siri → 透過揚聲器播報通知，將它開啟。
  4. 再到 設定 → 通知 → 播報通知，若清單中有 Telegram，開啟 Telegram 並選擇所有通知。

iOS 不允許一般網頁在完全關閉後持續執行語音。真正的背景提醒由既有 Telegram 推播負責，再交給 Siri 從 iPhone 揚聲器、AirPods 或 CarPlay 播報。可參考 Apple 的 Siri 輔助使用說明。
